# Mobile_sales_dashboard_using_powerBI-
🧭 Overview

This project is a three-page sales analytics dashboard built on a mobile sales fact table and a custom calendar/date table. It moves from a high-level overview down to focused time-based views for tracking pace and year-over-year growth.

Pages

1. MOBILE_SALES_DASHBOARD (Overview)

KPI cards: Total Sales, Total Quantity, Total Transactions, Average Price
Map: Total Sales by City (bubble size = sales)
Line chart: Total Sales trended by Month
Area chart: Total Sales by Day Name (weekday seasonality)
Bar chart: Total Sales by Mobile Model
Pie chart: Total Transactions by Payment Method
Funnel chart: transaction count by Rating Status
Table: Total Sales by Year / Quarter / Month
Slicers: Month, Mobile Model, Brand, Payment Method

2. MTD (Month-to-Date)

Same KPI card set as the overview page
Line chart: MTD measure across the full Year → Quarter → Month → Day hierarchy
Slicers: Month, Mobile Model, Year/Month, Payment Method

3. YTD (Year-to-Date)

Same KPI card set for consistency
Table: Total Sales vs. Sample Period Last Year, by Year / Quarter / Month / Day
Three clustered column charts comparing Total Sales vs. prior year, at date-hierarchy, Quarter, and Month granularity
Slicers: Month, Mobile Model, Year/Month, Payment Method
